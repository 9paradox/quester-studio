# Screenshots

Drop PNGs here to replace UI docs placeholders. Capture from the **desktop app** with the sample workspace and **`demo-main-nodes`** open.

## Files

| File | Scene |
|------|--------|
| `shell.png` | App chrome; `demo-main-nodes` selected in Flows sidebar |
| `canvas.png` | Full L→R flow graph on the canvas |
| `inspector.png` | Inspector on the `http` or `extract` node |
| `run-panel.png` | After a successful run — response/output visible |

## Capture checklist

1. Launch Quester Studio → **Open sample**
2. Select flow **demo-main-nodes**, env **local**
3. Arrange window for a clear shot of shell / canvas / inspector
4. Run once, then capture the run panel
5. Save into this folder with the filenames above
6. Swap placeholders in `src/pages/docs.astro` for `<img>` tags
